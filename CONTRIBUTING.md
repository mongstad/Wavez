# Development and Maintenance Policy

Wavez is an owner-maintained and owner-directed scientific visualization project.
Public visibility allows anyone to read or clone the source and documentation
without an invitation. Only authorized collaborators may push, administer or
merge changes; external contributions require explicit owner arrangement.
No public contribution intake is offered.
This policy does not change GitHub repository visibility or access settings.

The owner controls development priorities, review, acceptance and merging.
Authorized developers and agents follow [AGENTS.md](AGENTS.md) and the
[version policy](docs/VERSIONING.md).

## Licensing and releases

Original Wavez material uses the [PolyForm Noncommercial License 1.0.0](LICENSE).
It is **source-available**, not OSI-approved open source. Source availability is a
licensing distinction: public visibility does not change the license or grant
commercial use. Commercial use requires a separate agreement. Third-party
components retain their
[own licensing terms](THIRD_PARTY_LICENSES.md), and the name and artwork follow
the [branding policy](TRADEMARKS.md).

This policy creates no contributor license agreement, copyright assignment or
additional legal permission. Development authorization does not authorize tags,
release publication or artifact uploads; those require separate explicit owner
authorization.
