## Display and precision

Start/End use the authoritative playback clock formatter with an explicit
fractional display option. Whole-second playback formatting and seek parsing
retain their accepted behavior. Export keeps the original decimal-second
SpinBoxes alongside the clock, with an **s** suffix and input-syntax tooltip.
Custom entry remains decimal seconds with the existing four-decimal precision;
Full and Current retain their original float64 endpoints. Exact preset values
are visible in the clock and tooltip, including values finer than that editor's
display precision. Extremely small fractions retain exact scientific seconds
beside the zero clock rather than creating an unbounded string of zeros.

Playback rate has a **×** suffix. Duration uses the existing frame count/FPS,
with milliseconds where needed and **≈** for rounded values. Its tooltip keeps
the precise seconds and distinguishes video duration from processing time.
No settings serialization, source time units, range semantics, sampling or
rendering algorithm changed. Recorded timestamp offsets remain recorded offsets;
the playback elapsed clock remains relative to the first sample.

external Godot editor, then run from the issue branch's repository root:

```bash
mkdir -p /tmp/wavez-323-baseline
git archive 29037f6 | tar -x -C /tmp/wavez-323-baseline
/path/to/Godot --headless --path /tmp/wavez-323-baseline/viewer --editor --import
python tools/validate_video_time.py --godot /path/to/Godot \
  --baseline /tmp/wavez-323-baseline --output /tmp/wavez-323-forward \
  --renderer forward_plus
python tools/validate_video_time.py --godot /path/to/Godot \
  --baseline /tmp/wavez-323-baseline --output /tmp/wavez-323-compat \
  --renderer gl_compatibility
python tools/validate_video_time.py --godot /path/to/Godot \
  --baseline /tmp/wavez-323-baseline --output /tmp/wavez-323-package \
  --renderer gl_compatibility --package
```

Use fresh output directories. Native GPU/display access, NumPy/Pillow, external
FFmpeg/ffprobe and installed Linux export templates are required.
